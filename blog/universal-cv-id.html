Your Universal CV ID

One permanent ID that links every version of your CV and every application, wherever you send it.

The idea

Most people send a slightly different CV to every job. After a few weeks it is hard to remember which version went where, or to show that the CV a recruiter is holding is really yours and up to date.

A Universal CV ID would be a short code that belongs to you, not to a single file. Every CV you make and every application you log would sit under it.

Where it stands today

It is not live yet. The builder keeps your CVs and applications together in your own browser, but there is no ID you can share, nothing is registered online and nothing is verified.

What comes next

We want the ID to work beyond a single browser: the same ID on every device, one link that always shows your latest CV, and later a way for employers to check that an ID is genuine. That needs some data to be stored online, so before any of it launches we will update the privacy page, and nothing already in your browser will be uploaded without you choosing to.
